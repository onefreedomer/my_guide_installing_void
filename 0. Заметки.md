Просмотр прямых зависимостей у неустановленного пакета:
```bash
xbps-query -Rx <имя_пакета>
```

Вложенный просмотр зависимостей у неустановленного пакета:
```bash
xbps-query -R --fulldeptree <имя_пакета>
```

Удаление пакета с зависимостями, которые не нужны другим пакетам:
```bash
sudo xbps-remove -Ro <имя_пакета>
```

Включение сервиса в автозагрузку:
```bash
sudo ln -s /etc/sv/<сервис> /var/service
```

Управление сервисами:
```bash
sudo sv up <сервис>     # Включить сервис
sudo sv down <сервис>   # Выключить сервис
sudo sv status <сервис> # Статус сервиса
```

Перезапуск и выключение системы без root-прав (требуются пакеты `elogind` и `polkit`):
```bash
loginctl reboot
loginctl poweroff
```
