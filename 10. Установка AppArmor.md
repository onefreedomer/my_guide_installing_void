Установка AppArmor:
```bash
sudo xbps-install apparmor
```

Включение AppArmor:
```bash
sudo vim /etc/default/grub
```
```grub
...
GRUB_CMDLINE_LINUX_DEFAULT="... apparmor=1 security=apparmor"
```
Применение изменения для GRUB и перезапуск:
```bash
sudo update-grub
loginctl reboot
```

Проверка статуса работы AppArmor:
```bash
aa-enabled
sudo aa-status
```

Для смены режима работы AppArmor изменить переменную `APPARMOR` в файле `/etc/default/apparmor` на одну из представленных ниже:
- `disable` - никак не влияет на работу;
- `complain` - нарушения правил только фиксируются в логах;
- `enforce` - нарушения блокируются и фиксируются в логах.

Применение правил (возможна ситуация, что половина приложений перестанет запускаться):
```bash
sudo aa-enfore /etc/apparmor.d/*
```
