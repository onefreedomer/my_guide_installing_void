Установка niri и нужных ему утилит:
```bash
sudo xbps-install niri xwayland-satellite dejavu-fonts-ttf elogind upower \
	 sddm xorg-minimal \
	 xdg-desktop-portal-gtk xdg-desktop-portal-gnome
```
- `xwayland-satellite` - слой совместимости для запуска приложений для X Window System;
- `dejavu-fonts-ttf` - шрифты, которые использует по умолчанию niri;
- `elogind` - управляет пользовательскими сессиями и питанием;
- `upower` - пакет для вывода информации о заряде батареи;
- `sddm` - экран блокировки;
- `xorg-miminal` - минимальный набор пакетов X Window System для работы `sddm`.
- `xdg-desktop-portal-gtk` - основной портал GTK3, дающий возможность приложениям вызывать файловый менеджер, узнавать настройки темы интерфейса и др;
- `xdg-desktop-portal-gnome` - портал GNOME (GTK4) даёт возможность приложениям (например, Discord) включать демонстрацию экрана/окон. Включает в себя подобный функционал портала `xdg-desktop-portal-gtk`.

Создание окружения для сборки Noctalia v5:
```bash
git clone --depth 1 https://github.com/void-linux/void-packages.git
cd void-packages
./xbps-src binary-bootstrap
```

Копирование template-файла:
```bash
mkdir ./srcpkgs/noctalia
wget https://git.voiders.dev/voiders-community/repository/raw/branch/main/pkgs/noctalia/template \ 
-P ./srcpkgs/noctalia/template
```

Компиляция Noctalia v5:
```
./xbps-src pkg noctalia
```

Установка пакета Noctalia v5:
```bash
sudo xbps-install -R hostdir/binpkgs noctalia
```

Добавить в конец файла `~/.config/niri/config.kdl` строки для запуска оболочки Noctalia и xwayland-satellite:
```kdl
spawn-at-startup "noctalia"
spawn-at-startup "xwayland-satellite"
```

Создать директорию `~/.cache` и `~/.local/bin`, если такие не существуют:
```bash
mkdir -p "$HOME/.cache"
mkdir -p "$HOME/.local/bin"
```
Скрипт для запуска `~/.local/bin/start-niri`:
```bash
#!/usr/bin/bash

# Нужно для полноэкранного режима на VirtualBox
# rcvboxadd start         
# rcvboxadd-service start

# Нужно для корректного отображения окна kitty на VirtualBox.
# export LIBGL_ALWAYS_SOFTWARE=1
# export GALLIUM_DRIVER=llvmpipe

dbus-run-session -- sh -c '
	pipewire > "$HOME/.cache/pipewire.log" 2>&1 &
	exec niri --session > "$HOME/.cache/niri.log" 2>&1
'
```

Конфигурация десктоп-файла для niri `/usr/share/wayland-session/niri.desktop` (нужно для корректного запуска niri из SDDM):
```desktop
[Desktop Entry]
Name=Niri
Comment=A scrollable-tiling Wayland compositor
Exec=/home/one/.local/bin/start-niri
Type=Application
DesktopNames=niri
```
Настройка `xdg-desktop-portal` для записи/демонстрации экрана:
```bash
sudo vim /usr/share/xdg-desktop-portal/niri-portals.conf
```
```portal
org.freedesktop.impl.portal.Screenshot=gnome;
org.freedesktop.impl.portal.ScreenCast=gnome;
```

Установка темы курсора [Bibata Classic](https://github.com/ful1e5/Bibata_Cursor/releases):
```bash
tar --extract --file Bibata-Modern-Classic.tar.xz
sudo mkdir -p /usr/share/icons/Bibata
sudo mv Bibata-Modern-Classic/* $_
```
Добавить в конец файла `~/.config/niri/config.kdl` название темы курсора:
```kdl
cursor {
	xcursor-theme "Bibata"
	xcursor-size 20
}
```

Установка темы SilentSDDM:
```bash
git clone -b main --depth=1 https://github.com/uiriansan/SilentSDDM
cd SilentSDDM
```
Проверка на работоспособность темы:
```
./test.sh
```
Если все в порядке - тема отображается, то установить её файл конфигурации:
```
./install.sh
```

Установка темы курсора Bibata в SDDM и приложениях для X Window System:
```bash
sudo mkdir -p /usr/share/icons/default
sudo vim $_/index.theme
```
```theme
[Theme]
Inherits=Bibata
```
Добавить размер курсора в `/etc/sddm.conf`:
```conf
[Theme]
Current=silent
CursorSize=20
```

Включение сервиса `sddm`:
```bash
sudo ln -s /etc/sv/sddm /var/service
```
