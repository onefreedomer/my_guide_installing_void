Установка cronie:
```bash
sudo xbps-install cronie
```

Установка почты (нужна для того, чтобы cronie мог слать отчеты о том, что выполнил команду по расписанию):
```bash
sudo xbps-install opensmtpd
```
Установить в `~/.bashrc` путь к почтовому ящику:
```bash
export MAIL="$HOME/Maildir"
```
Включение почты:
```bash
sudo ln -s /etc/sv/opensmtpd /var/service
```
```bash
echo "text" | sendmail user # Отправить письмо локальному пользователю
mail                        # Проверить свой почтовый ящик, '-u user' для чужого
```

Пользователь, которому будут отправляться отчеты, определяется полем `MAILTO=пользователь` в crontab (открыть crontab - `crontab -e`). Для каждого пользователя индивидуальный crontab.
## 12.1. TRIM SSD-накопителей
При условии, что колонки DISC_GRN и DISC_MAX не равны 0, делать следующие шаги:
```bash
lsblk --discard
```

Скрипт для очистки данных на SSD, которые можно не хранить:
```bash
sudo vim /etc/cron.weekly/fstrim
```

```bash
#!/usr/bin/bash

fstrim /
```
Сделать скрипт исполняемым:
```bash
sudo chmod u+x /etc/cron.weekly/fstrim
```
## 12.2. Обновление данных о пакетах репозитория при перезапуске
Скрипт для синхронизации XBPS репозитория:
```bash
sudo vim /etc/cron.d/xbps-sync-reboot
```
```crontab
SHELL=/usr/bin/bash
PATH=/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin
MAILTO=root

@reboot xbps-install -S
```

## 12.3 Пример использования anacron (cron для компьютеров, не работающих 24/7)

Файл crontab для anacron (включен в пакет `cronie`):
```bash
sudo vim /etc/anacrontab
```
```crontab
@yearly echo "Happy New Year!"
```
Сервис anacron позволяет выполнять редкие по частоте задачи, даже если в нужный момент компьютер был выключен.
