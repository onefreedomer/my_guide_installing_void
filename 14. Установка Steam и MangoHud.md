Установка Steam:
```bash
sudo xbps-install steam
```

Дополнительные 32-битные библиотеки для работы:
```bash
sudo xbps-install libgcc-32bit libstdc++-32bit libdrm-32bit libglvnd-32bit libva-32bit
```

Для большинства игр желательно в параметрах запуска установить команду (только для пользователей видеокарт NVIDIA): 
```bash
prime-run %command%
```

Подготовка для компиляция MangoHud с поддержкой статистики для видеокарт NVIDIA, оверлей для мониторинга параметров системы:
```bash
cd void-packages # Локальный репозиторий Void Linux
mkdir ./srcpkgs/MangoHud-nvidia
./xbps-src -m masterdir-i686 -A i686 binary-bootstrap
```

[Файл заготовки](./scripts/MangoHud-nvidia/template) ([оригинальный файл находится здесь](https://github.com/gmbeard/void-packages/blob/feature/MangoHud-nvidia/srcpkgs/MangoHud-nvidia/template)):
```bash
vim ./srcpkgs/MangoHud-nvidia/template
```

Компиляция 64- и 32-битных версий MangoHud:
```bash
./xbps-src pkg MangoHud-nvidia
./xbps-src -m masterdir-i686 pkg MangoHud-nvidia
```
64- и 32 битные версии оверлея используются в соответствующих по битности играх.  
Установка скомпилированных пакетов:
```bash
sudo xbps-install -R ./hostdir/binpkgs/nonfree MangoHud-nvidia
sudo xbps-install -R ./hostdir/binpkgs/multilib/nonfree MangoHud-nvidia
```

Для отображения оверлея в игре добавить в параметры запуска:
```
mangohud %command%
```
В частности, мои параметры запуска:
```bash
PROTON_USE_WOW64=1 MANGOHUD_CONFIGFILE=/home/<ваше_имя>/.config/MangoHud/MangoHud.conf prime-run mangohud %command%
```
Первая переменная требуется для корректного отображения мощности видеокарты, вторая отвечает за расположение файла конфигурации.
