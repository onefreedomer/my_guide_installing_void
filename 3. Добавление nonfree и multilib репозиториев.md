Включение nonfree и multilib (официальных) репозиториев (для драйверов NVIDIA, 32-битных библиотек и т. п.): 
```bash
sudo xbps-install void-repo-nonfree void-repo-multilib void-repi-multilib-nonfree
sudo xbps-install -S
```

Проверка общего количества пакетов в каждом из репозиториев:
```bash
xbps-query -L
```
