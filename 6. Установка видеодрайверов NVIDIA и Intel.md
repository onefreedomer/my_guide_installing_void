Узнать свое семейство видеокарт NVIDIA:
```bash
lspci -k -d ::03xx
```

| Семейство                           | Драйвер     |
| ----------------------------------- | ----------- |
| Turing (NV160)                      | `nvidia`    |
| От Maxwell (NV110) до Volta (NV140) | `nvidia580` |
| Kepler (NVE0)                       | `nvidia470` |
| Fermi (NVC0)                        | `nvidia390` |
Установка драйверов для RTX 3060 (Ampere, NV170)
```bash
sudo xbps-install nvidia nvidia-libs-32bit
sudo reboot
```
Дальше проверить логи ядра на наличие ошибки о том, что устройство не поддерживается:
```log
NVRM: The NVIDIA GPU xxxx:xx:xx.x (PCI ID: xxxx:xxxx)
NVRM: installed in this system is not supported by the xxx.xx
NVRM: NVIDIA Linux driver release.  Please see 'Appendix
NVRM: A - Supported NVIDIA GPU Products' in this release's
NVRM: README, available on the Linux driver download page
NVRM: at www.nvidia.com.
```
Если это произойдет, то установить `nvidia390` драйвер.

Для запуска приложения с использованием видеокарты NVIDIA команда:
```bash
prime-run <приложение>
```

Установка драйверов для Intel:
```bash
sudo xbps-install intel-media-driver intel-ucode \
				  mesa-dri \                      # OpenGL
				  vulkan-loader mesa-vulkan-intel # Vulkan
```
В файле `/etc/profile` добавить переменную окружения:
```bash
export LIBVA_DRIVER_NAME=iHD
```
