Установка [tlp](https://linrunner.de/tlp/) и его дополнений:
```bash
sudo xbps-install tlp tlp-pd
```
- `tlp` служит для настройки режимов работы батареи с root-правами;
- `tlp-pd` служит для настройки режимов работы батареи без root-прав (требуется `dbus`);

Включение tlp:
```bash
sudo ln -s /etc/sv/tlp /var/service
sudo ln -s /etc/sv/tlp-pd /var/service
```

Установка драйверов Bluetooth:
```bash
sudo xbps-install bluez
```

Включение Bluetooth сервиса:
```bash
sudo ln -s /etc/sv/bluetoothd /var/service
```
